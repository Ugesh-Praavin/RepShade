# Security Policy

## Supported Versions

We release patches and security fixes for the latest version of RepShade.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The RepShade team takes the security of our application and user data seriously. If you believe you have discovered a security vulnerability in RepShade, please report it to us responsibly.

### How to Report

**Please DO NOT report security vulnerabilities through public GitHub issues.**

Instead, please report security issues privately by:
- Sending an email to **security@repshade.app** with details of the vulnerability.
- Or using GitHub's **Private Vulnerability Reporting** feature directly on the repository settings page.

### What to Include in Your Report

Please include as much information as possible to help us reproduce and fix the issue quickly:
- Type of issue (e.g. data leak, authentication bypass, injection vulnerability)
- Full paths, routes, or components involved
- Step-by-step instructions to reproduce the vulnerability
- Proof-of-concept code or payload (if applicable)
- Impact assessment of the issue

### Preferred Disclosure Process

1. We will acknowledge receipt of your vulnerability report within 48 hours.
2. We will provide a preliminary assessment and estimated fix timeline within 5 business days.
3. Once the issue is resolved and a patched version is published, we will coordinate public disclosure with credit to the reporter.

Thank you for helping keep RepShade and our community safe! 🛡️
